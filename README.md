# Mobius Topology Racer

A single-file Three.js topology playground, Game of Life surface, and tiny racing game.

Open `index.html` directly, or run it as a static Node site:

```bash
npm start
```

Then visit `http://localhost:3000`.

## Courses

- Möbius Strip — default
- Diamond Ring
- Figure-Eight Möbius
- Trefoil Track

## Controls

- Click cells to toggle Game of Life cells.
- Run Life / Random Life from the top-right controls.
- Race Mode uses arrow keys.
- Orange cells boost, dim cells slow, red cells are hazards.

Desktop browser with WebGL recommended.
